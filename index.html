HCI Topic 3 (Inclusive Design) & Topic 8 (Visual Haptic Emulation)

Topic 3: Inclusive Design & WCAG 2.1 Framework

Level AA & AAA

The 4 WCAG Pillars (POUR):

  • Perceivable (1.4.1, 1.4.3): Information must not rely on a single sensory modality (e.g., swatches use shape + text + color; contrast ratio $\ge 4.5:1$).
  • Operable (2.1.1, 2.4.7): Complete keyboard operability without traps; visible focus indicators with minimum $3:1$ contrast against adjacent background.
  • Understandable (3.3.1): Clear, textual error identification with explicit error remediation steps.
  • Robust (4.1.2): WAI-ARIA states, roles, and values ensuring cross-compatibility with screen readers.

Topic 8: Visual Haptic & Tactile Emulation

Cross-Modal Synthesis

Cross-Modal Sensory Substitution Principle:

When hardware actuators (vibration motors) are missing or in browser-only web environments, sensory feedback can be emulated by synchronizing:

  • Mechanical Spring Travel: Micro-squash and stretch (.tactile-bump) simulating physical key depression.
  • Wave Dispersion: Radial shockwave (.haptic-ripple) simulating vibration propagation across a surface.
  • Boundary Collision Recoil: Edge-of-screen flash & synthetic low-frequency acoustic bump on reaching slider bounds (0 or 5 quantity limit).
  • Synthetic Web Audio Click: Dual-sensory confirmation using native Web Audio API oscillators (zero audio files or mic needed).

Examiner Demonstration Script

  1. Show Swatch Multi-Cues: Open Adaptability Engine → Enable Achromatopsia. Notice how the swatches remain 100% identifiable because each has a distinct geometric symbol (Circle, Square, Triangle, Diamond).
  2. Demonstrate Dyslexia Adaptation: Enable OpenDyslexic font + Wide Spacing + Reading Ruler. Explain how bottom-weighted glyphs prevent letter inversion.
  3. Demonstrate Visual Haptics: Click quantity increment until it hits 5. Observe the tactile boundary recoil flash and acoustic micro-tick.
  4. Demonstrate Keyboard Navigation: Press Tab from top. See the "Skip to main content" link and pulsating high-visibility focus ring.
